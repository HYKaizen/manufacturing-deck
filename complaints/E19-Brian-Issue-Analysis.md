## 🟠 ISSUE #2: MICROWAVE ELECTRICAL (P2 - 24-48hrs)

### **Problem Analysis:**
- Microwave trips breaker after few seconds on 120V shore power
- Fridge operates normally on same circuit
- Issue persists at customer's home (rules out campground power)

### **Electrical Troubleshooting:**

**Circuit Analysis:**
```
Normal microwave startup current: ~12-15A
E19 shore power breaker rating: ? (verify)
Possible causes:
□ Defective microwave (internal short)
□ Wrong breaker rating for microwave load
□ Wiring fault (loose connection, damaged wire)
□ GFCI interaction issue
□ Incorrect circuit design (microwave + other loads)
```

### **Diagnostic Steps:**
1. **Amp clamp test** - measure actual draw before trip
2. **Insulation resistance** test on microwave
3. **Circuit load analysis** - what else on same breaker?
4. **Voltage drop** test under load
5. **Microwave bench test** on known good circuit

### **Quick Field Test:**
```
□ Test microwave on isolated 20A circuit
□ Check voltage at microwave outlet under load
□ Verify all wire connections tight
□ Test GFCI function (if present)
```
